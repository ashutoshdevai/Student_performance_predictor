# Student Performance Predictor

## About the Project
Student Performance Predictor is a Machine Learning web application built using Python and Streamlit. It predicts students' expected final scores based on study hours, attendance, assignments, previous scores, and sleep hours.

## Features
- Predicts students' expected final scores
- Uses Machine Learning with Linear Regression
- Simple and interactive Streamlit interface
- Accepts multiple student performance inputs

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit

## Installation
Install the required libraries:

```bash
pip install streamlit pandas scikit-learn
```

## Run the Application
```bash
streamlit run app.py
```
